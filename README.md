# Potter English

Мобильное PWA для английского B2 по **Harry Potter and the Sorcerer's Stone**. Американский текст из предоставленного пользователем EPUB, британская синтетическая озвучка **Microsoft en-GB-RyanNeural**. Русский интерфейс, самостоятельное вспоминание, поиск, типы выражений, главы и избранное. В категорию «Идиомы и обороты» входят также устойчивые разговорные формулы; глагольный раздел включает фразовые и предложные глаголы.

## Доступ и установка

Публикация: https://evgk724.github.io/potter-english/

[QR для установки](https://evgk724.github.io/potter-english/icons/install-qr.png) · [Проверки и покрытие](docs/verification.md)

На iPhone/iPad откройте ссылку в Safari → «Поделиться» → «На экран Домой». Откройте установленное приложение → «Офлайн» → «Скачать для офлайн» и дождитесь подтверждения. Первый запуск и загрузка требуют сети. Сохраняются все выбранные MP3, включая ещё не прослушанные; можно загрузить только главу. iOS может удалить данные сайта: приложение проверяет наличие и SHA-256 файлов при открытии.

## Содержание и границы

В наборе **1 253 карточки**: 411 фразовых/предложных глаголов, 391 идиома и устойчивый оборот, 451 коллокация. Это число отдельных выражений и значений; одна карточка может относиться к нескольким главам.

Все 17 глав загруженного EPUB прочитаны. Выражения проверяются по коротким локальным свидетельствам исходника; публичные карточки содержат лемму, значение, грамматическое пояснение, **собственный** учебный пример и перевод. Повторные появления объединены с сохранением глав, различающиеся значения выделены. Окончательные числа и метод проверки — в `coverage.json`.

Это содержательный проход по всей книге, а не заявление об абсолютной полноте открытого класса коллокаций. EPUB не содержит проверенных ISBN/издателя; приложение не приписывает ему конкретную издательскую печать. Сам EPUB, извлечённый текст и короткие свидетельства находятся в исключённой из Git папке `private/` и никогда не входят в приложение, service worker, GitHub или CI. Приложение не официальное и не связано с правообладателем.

## Приватность и прогресс

Аккаунтов, аналитики, внешних шрифтов и клиентских ключей нет. Избранное, повторы и дополнительные локальные наборы сохраняются под `potter-english-v1` в браузере этого устройства. Другие учебные приложения не затрагиваются. Синхронизации между устройствами нет; есть экспорт и восстановление резервной копии.

Дополнительный TXT-импорт выполняет только словарный поиск известных выражений, а не универсальное извлечение всех фраз. Совпадения из TXT помечены как кандидаты; значения нужно подтвердить в разборе карточки, прежде чем они попадут в практику. Разные значения одинаковой формы сохраняются отдельно. Импорт ограничен 2000 карточками без молчаливого усечения. Исходный TXT после обработки не сохраняется и не отправляется. JSON-импорт валидирует поля и локальные ссылки на аудио. Новые произвольные карточки не получают голос автоматически: необходима генерация проверенных MP3.

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
# http://127.0.0.1:4173/
node --test tests/*.test.mjs
python3 scripts/build.py
```

Для разработки достаточно Python 3.11+ и Node 24. Приложение работает без сборщика, сторонних UI-библиотек и CDN. `scripts/build.py` проверяет полное аудиопокрытие, размеры и хеши, затем копирует только разрешённые публичные ресурсы в `dist/`. GitHub Actions запускает тесты, сборку и Pages deployment.

## Ryan

Предварительная генерация использует `edge-tts==7.3.1`. MP3 воспроизводятся через HTML Audio, включая сохранённые ответы Range в WebKit. Web Speech и подмена другим голосом не используются. В `audio/manifest.json` записаны голос, точный учебный текст, размеры, SHA-256 и длительности. Скрипт генерации отправляет Microsoft только выражение и авторский английский пример.

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements-audio.txt
.venv/bin/python scripts/generate_audio.py --concurrency 2
.venv/bin/python scripts/generate_audio.py --check
```

Первичные сведения о голосе и генераторе: [Microsoft Speech voices](https://learn.microsoft.com/azure/ai-services/speech-service/language-support?tabs=tts), [edge-tts](https://github.com/rany2/edge-tts). Фактическая генерация проверяет живой список голосов, декодирует каждую запись и проверяет ненулевую громкость. Повторный запуск продолжает недостающие файлы.
